Build me a simple, well-structured ad-blocking command-line tool in Rust for my MacBook. It manages the /etc/hosts file. Use /rust for all code.

## What it does
Downloads a public ad/tracker blocklist, validates it, and writes it into /etc/hosts between markers so ad domains resolve to 0.0.0.0. This blocks ads across every browser and app on my Mac. Keep it simple: a single Rust binary driven by a Justfile. No GUI, no background services.

## Commands
- `adblock update`: download lists, validate, merge with my custom blocks, subtract my allowlist, save the result to a cache file in ~/Library/Application Support/adblocker/. Runs as my normal user.
- `adblock apply`: re-validate the cached list and write it into /etc/hosts. Needs sudo; if not run as root, print a clear message telling me to use `just apply`.
- `adblock disable`: remove the marked block from /etc/hosts (sudo).
- `adblock status`: on/off, domains blocked, last update, sources.
- `adblock allow <domain>` / `adblock block <domain>`: edit my allowlist and custom blocks.

## Rules
- Default source: StevenBlack unified hosts, https://raw.githubusercontent.com/StevenBlack/hosts/master/hosts
- Only accept lines mapping to 0.0.0.0 or 127.0.0.1 with a valid domain name. Reject and count everything else; never write an entry pointing a domain to any other IP.
- A small built-in protected list that can never be blocked (the blocklist source host, Apple software update, iCloud). Look up the correct Apple domains.
- Only touch content between `# BEGIN AD-BLOCKER` and `# END AD-BLOCKER`. Leave macOS's default entries and everything else alone. If the markers are broken (missing END, duplicated), stop and explain rather than guess.
- Before the first change, back up the original to /etc/hosts.adblocker-backup. Write atomically (temp file in /private/etc, then rename), keep root:wheel 644, refuse if /etc/hosts is a symlink.
- Never write if a download or validation fails, or if the list comes out empty.
- Flush DNS after every write: `dscacheutil -flushcache; killall -HUP mDNSResponder`.
